# Changelog

All notable changes, by build phase. (Single-developer project; each phase maps to an
implementation iteration in the project report.)

## Phase 6 – Hardening and documentation
- Full suite: 88 tests (unit, integration, system, security and governance), 87 % line coverage
  of `app/` (excl. UI); `docs/test_report.md` generated by `scripts/make_test_report.py`.
- `ruff check` and `ruff format` clean. README, `docs/DEMO_SCRIPT.md`, `scripts/start_demo.ps1`.

## Phase 5 – Release monitoring, review, integration and UI (modules 3.8, 3.9)
- `ReleaseMonitorAgent`, `IncrementalDocUpdater` (content hash, versioning, one transaction),
  APScheduler job with replay of missed releases (`last_processed_release_id`).
- Confluence client (Mock writes HTML, Live REST) and `ConfluenceSyncAgent`.
- Notification service (Observer), admin service, RBAC, Streamlit Home + 9 pages, Review Queue.
- Tests: IT-03, IT-04, SG-01, SG-02, SG-03, UI smoke tests.

## Phase 4 – Test case generation and execution (modules 3.6, 3.7)
- `TestGeneratorAgent`, `TestExecutionAgent`, `MockRunner` / `LocalCommandRunner`, manual results,
  QA sign-off, results upload to ADO Test Plans (mock/live).

## Phase 3 – User story and code generation (modules 3.4, 3.5)
- `StoryGeneratorAgent` with INVEST check, ADO work item on approval (IT-02).
- `CodeGenerationAgent` (difflib diff, javalang validation), `AdoReposConnector`, adoption only
  after approval (ST-02). `AdoClient` interface with Mock and Live implementations.

## Phase 2 – As-is documentation and requirement/impact analysis (modules 3.1, 3.3)
- Sample Java payments app (16 files, nested class + interfaces), requirements, guidelines,
  baseline specs, mock ADO fixtures.
- `BaseAgent` (Template Method), `ApprovalService` (state machine, audit in one transaction),
  `WorkflowOrchestrator` (server-side APPROVED gate), `JavaParserAgent`, `ImpactAnalysisAgent`
  (Pydantic validation, retry, grounding check). Tests UT-01, UT-02, UT-05, UT-06, ST-01, ST-03.

## Phase 1 – Database, configuration, knowledge base and RAG (module 3.2)
- 16 SQLAlchemy models (+ `notification`), CHECK constraints, HNSW + B-tree indexes, append-only
  audit trigger, seed users/guidelines. LLM clients (Groq, Azure OpenAI, Mock), embedding service,
  `PgVectorStore`, retriever (search, re-rank, threshold, baseline fallback), retrieval log,
  masking service. Tests UT-03, UT-04, UT-07, IT-01.

## Phase 0 – Project setup
- Folder structure, `requirements.txt`, `pyproject.toml` (ruff, pytest), `.env.example`,
  `.gitignore`, `docker-compose.yml` (pgvector/pg16, host port 5460), `app/config.py`.
- Deviations from the brief: Python 3.12 instead of 3.11 (only version installed); host port 5460
  because 5432/5433 were taken by other containers.
